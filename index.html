Como abrir um chamado

  1. Clique no botão abaixo "Abrir novo chamado".
  2. Você será direcionado ao GitHub (pode ser necessário criar uma conta gratuita, leva 1 minuto).
  3. Preencha o formulário com os detalhes do problema/solicitação.
  4. Clique em "Submit new issue" para enviar. O ponto focal de TI será notificado automaticamente.
